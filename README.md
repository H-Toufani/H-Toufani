## 🔬 The project to start with

### [Spinal Cord MRI · Preprocessing + 3D U-Net](https://github.com/H-Toufani/spinalcord-mri-preprocessing)

A public research codebase for MRI acquired across different imaging sites and conditions.

| Stage | What happens |
| :--- | :--- |
| 🧹 Prepare | Resampling, cropping, N4 bias correction, denoising, normalization |
| 🔎 Enhance | Contrast enhancement and edge-aware representations |
| 🧠 Learn | Single-channel and multi-channel 3D U-Net with PyTorch + MONAI |
| 📏 Evaluate | Image quality, Dice, precision, recall, and cross-dataset evaluation |

**[Explore the code →](https://github.com/H-Toufani/spinalcord-mri-preprocessing)**  
Source code, dependencies, and workflow docs are available. Clinical MRI datasets are not distributed with the repository.
